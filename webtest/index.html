02 / 张量运算

张量可以理解为多维数值数组。这里将两个向量逐项相加，再计算矩阵乘法。

tf.tidy(() => {
  const a = tf.tensor1d([1, 2, 3]);
  const b = tf.tensor1d([10, 20, 30]);
  console.log(a.add(b).arraySync()); // [11, 22, 33]
}); // 自动释放作用域内未返回的张量

等待运行。

03 / 训练一个线性模型

给模型提供 x 与 y 的样本，让它学习 y = 2x + 1。模型只有一个神经元，学习权重 w 和偏置 b，使 y ≈ wx + b。

const model = tf.sequential();
model.add(tf.layers.dense({ units: 1, inputShape: [1] }));
model.compile({ optimizer: tf.train.sgd(0.1), loss: 'meanSquaredError' });
await model.fit(xs, ys, { epochs: 100 });
